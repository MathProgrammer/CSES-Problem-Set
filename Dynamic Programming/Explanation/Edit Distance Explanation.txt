Let us define f(i, j) as the number of moves required to make the first J characters of N equal to the first I characters of M. 

Let us see the possible transitions 

If M[i] = N[j], then f(i, j) = f(i - 1, j - 1). 

Let us see what happens when M[i] =/= N[j] 

------

Case 1 - Update 

We update N[j] to be equal to M[i]. 

This means we now have to make the first (j - 1) characters of N match the first (i - 1) characters of M. 

f(i, j) = 1 + f(i - 1, j - 1) 

------

Case 2 - Insert

We insert a new character after the j-th position of N. 

This means we have to now make the first (j) characters of N match with the first (i - 1) characters of M. 

f(i, j) = 1 + f(i - 1, j) 


------

Case 3 - Delete 

Delete N[j]. 

We now have to make the first (j - 1) characters of N match with the first (i) characters of M. 

f(i, j) = 1 + f(i, j - 1)

-----

We will choose the minimum of these 3 cases. 

-----

Let us also discuss the base case when one of the strings (or both) is empty. 

f(i, j) 

If i = 0, then we must delete all the characters of N. f(i, j) = j

If j = 0, then we must insert all the characters in M, f(i, j) = i

-------

int min_3(int x, int y, int z)
{
    return min(x, min(y, z));
}
 
int main()
{
    string M, N;
    cin >> M >> N;
 
    const int oo = 1e9;
    vector <vector <int> > distance(M.size() + 1, vector <int> (N.size() + 1, oo));
    for(int i = 0; i <= M.size(); i++)
    {
        for(int j = 0; j <= N.size(); j++)
        {
            if(i == 0 || j == 0)
            {
                int insert_cost = (j == 0 ? i : 0);
                int delete_cost= (i == 0 ? j : 0);
                distance[i][j] = (i == 0 ? delete_cost : insert_cost);
                continue;
            }
 
            if(M[i - 1] == N[j - 1])
            {
                distance[i][j] = distance[i - 1][j - 1];
            }
            else
            {
                int update_cost = 1 + distance[i - 1][j - 1];
                int insert_cost = 1 + distance[i - 1][j];
                int delete_cost = 1 + distance[i][j - 1];
 
                distance[i][j] = min_3(update_cost, insert_cost, delete_cost);
            }
        }
    }
 
    cout << distance[M.size()][N.size()] << "\n";
}
